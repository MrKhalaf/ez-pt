# Rehabber - iOS Setup

## Install as App

1. Open the app URL in **Safari** (required for PWA)
2. Tap the **Share** button (square with arrow)
3. Select **"Add to Home Screen"**
4. Tap **Add**

The app will run full-screen like a native app.

## Local Development

```bash
npm install
npm run dev
```

Access from iOS device: `http://[YOUR_LOCAL_IP]:5552`

Find your IP with: `ipconfig getifaddr en0`
